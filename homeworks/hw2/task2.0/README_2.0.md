# Домашнее задание 2.0:
## Минимальный детектор на DETR/Deformable-DETR

### Описание
*Решение [ДЗ2](HW2.md).*

Реализовано:
1. Подготовка данных с аугментацией (detection-datasets/coco)
2. Из датасета выделено 10 классов со схожей частотностью в train
3. Fine-tuning facebook/detr-resnet-50-dc5 на датасете
4. Логирование в TensorBoard
5. Профилировка обучения модели
6. Насчёт метрик: (Map (50/75, Small/Medium/Large) + Mar(1/10/100, Small/Medium/Large) + (Map, Mar 100) по каждому классу)
7. Оценка ошибок: процентное отсутсвие локализации + матрица ошибок классификации

### Инструкция запуска
Решение оформленно в виде Jupyter Notebook

### Эксперимент
* Датасет: detection-datasets/coco (10 классов).
* Классы: "bicycle", "motorcycle", "airplane", "train", "bird", "cat", "dog", "horse", "cow", "elephant"
* Модель: facebook/detr-resnet-50-dc5
* learning_rate=1e-5, weight_decay=1e-4, num_train_epochs=10
* train_runtime= 29621.4405 ~ (8.15ч)

### Ключевые наблюдения
* В первый раз пробовал на классах с разными частотами вхождения в датасет — обучение шло очень медленно
* В целом модель обучается довольно медленно даже на не очень большом датасете
* Удалось довести метрики модели до приемлемого уровня (метрики можно посмотреть в .csv)
* Модель довольно увенна в прогнозах, на каждый класс число пропусков локализации не более 20
* Модель довольно точна в задаче классификации: исключение только коровы, которых она путает с лошадьми и слонами
